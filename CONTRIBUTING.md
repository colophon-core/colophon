# Contributing to Colophon

Thanks for reading the printer's marks. This project is open source under the
MIT license, and contributions of all kinds are welcome — code, documentation,
translation, and careful review of the chain rules.

## Ground rules

- Keep the launch fair: no allocations, no private sales, no changes to the
  published emission schedule outside an open hard-fork discussion.
- Be precise. Numbers in this repository are consensus parameters — mistakes
  are the most expensive kind of bug here.
- Be kind. Small project, real people.

## How to contribute

1. Open an issue first for anything larger than a typo, so the direction is
   agreed before the work.
2. Fork the repository and make your changes on a branch.
3. Run the relevant checks (build, tests, documentation links).
4. Open a pull request describing what changed and why.

## Documentation

The docs live in [`docs/`](docs/). If you change a consensus parameter, update
all of the following together: `README.md`, `WHITEPAPER.md`, `docs/`, and the
site pages under `downloads/` and `explorer/`.

## Security

If you find a vulnerability in the wallet or the consensus code, do not open a
public issue. Write to the repository maintainers directly so the report can
be handled privately.

## Code of conduct

Harassment of any kind is not tolerated. Everyone participates on the same
terms — the same rules for everyone, on and off the chain.
