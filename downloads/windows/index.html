After downloading, compare the SHA-256 of the archive against the published value. On Windows PowerShell:

Get-FileHash .\colophon-wallet-windows-0.1.0.zip -Algorithm SHA256

The two values must match exactly. The source code is public on GitHub under the MIT license, so the build can also be reproduced from source.
