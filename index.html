COLOPHON

Every block carries its printer's mark.

In the old printing shops, the last page of a book carried a small closing note — the colophon — naming the printer, the date and the place. Colophon is a fair-launch KawPow coin built on the same habit: a public ledger where every block ends with a mark anyone can read, and nothing is printed off-record.

The colophon

A printed page can be read from start to finish, and the colophon at the end tells you who set it. Colophon applies that discipline to money — the chain is the print run, and every block is a page set in public view.

Fair from the first block

No premine, no ICO, no founder allocation. The first CLPH is mined like the last one. Nobody gets a head start.

GPU-minable

KawPow, ASIC-resistant by design. Ordinary graphics cards can take part — the network is for many hands, not a few warehouses.

Verifiable, not promised

Open source under MIT. Every number below is a rule of the chain, not a road-map wish.

The editions

The supply is issued in editions, and each new edition is half the size of the one before it. The schedule is a function of block height, not anyone's decision.
