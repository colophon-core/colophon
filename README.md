# Colophon (CLPH)

**Every block carries its printer's mark.**

Colophon is a fair-launch proof-of-work cryptocurrency named after the small
closing note that old printing shops set at the end of a book — the colophon —
naming the printer, the date and the place. The ledger works the same way:
the chain is the print run, every block is a page set in public, and the mark
at the end of each block tells you who mined it and under which rules.

- **Algorithm:** KawPow — GPU-minable, ASIC-resistant
- **Consensus:** Proof-of-Work, retarget every block
- **Block time:** 115 seconds
- **Block emission:** 28 CLPH
- **Halving:** every 520,000 blocks (≈ 1.90 years)
- **Maximum supply:** 28,210,000 CLPH
- **Premine / ICO:** 0 / 0 — fair launch

## Why "Colophon"

A printed page can be read from start to finish, and the colophon tells you
who set it. Colophon applies the same discipline to money: no founder
allocation, no token sale, no early window. The first coin is mined exactly
like the last one, and the supply schedule is fixed by the block height, not by
anyone's decision.
